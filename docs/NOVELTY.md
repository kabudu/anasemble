# Novelty Diligence

## Candidate claim

After verified loss of every deployable artifact for a supported component,
collect independently placed executable contracts, typed traces, and state
fragments; synthesize a non-identical replacement within a finite grammar; certify
it using an independently implemented checker and held-out obligations; deploy
only when all mandatory evidence is satisfied, otherwise refuse.

## What is established

Program synthesis from examples/specifications, distributed synthesis,
self-stabilizing protocol synthesis, software architecture reconstruction,
self-construction, semantic recovery, replication/erasure coding, and runtime
conformance checking are established. None is claimed.

## Diligence result

The preliminary sweep found all ingredients separately and adjacent work on
self-construction, but no exact academic or product match for the narrow
total-artifact-loss protocol. This is a candidate research gap, not proof of
patentability, freedom to operate, worldwide novelty, or market demand. The
strongest non-claim is that specification-guided synthesis already constructs
programs from behavioral constraints.

Do not market this as arbitrary program resurrection or recovery from no
information. Publication requires a systematic review and empirical evidence.
