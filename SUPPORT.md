# Support

Anasemble is community-supported software with no warranty or guaranteed service
level. Use GitHub issues for reproducible defects and documentation problems, and
discussions for usage questions and design proposals after those facilities are
enabled. Use the private process in `SECURITY.md` for vulnerabilities.

Always state the Anasemble commit or version, platform, compatibility profile,
sanitised configuration shape, exact command, observed result and expected
result. Review support bundles before sharing them. Never post credentials,
signing material, fragments, customer data, private paths or unredacted recovery
receipts.

Maintainers prioritise supported profiles, security and data-loss risks,
regressions and well-isolated reports. Experimental or unsupported combinations
may be accepted as evaluation evidence but do not carry a fix commitment.
